BIZITZA — NÚCLEO DO SER

1. Extraia a pasta bizitza-site.
2. Abra o ficheiro index.html num navegador.
3. Não mova o index.html, style.css, script.js ou a pasta assets separadamente.
4. A reflexão em destaque pode ser alterada através de “Área do administrador”.
5. Palavra-passe inicial do editor local: bizitza2026

NOTA: esta é uma funcionalidade de administração local para uma versão estática.
As alterações ficam guardadas no navegador (localStorage) e não sincronizam entre computadores/visitantes.
Para administração real num site online, será necessário ligar o editor a um CMS ou backend com autenticação.
